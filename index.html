Slide 05 / Linux 優缺點

Linux Pros and Cons Linux 的好與壞

Free and Open-SourceMost distributions (like Ubuntu, Fedora, or Linux Mint) cost nothing and let you view or modify the source code.

Resource EfficientUses less RAM and storage, often booting or restarting twice as fast as Windows on identical hardware.

Better SecurityFeatures a stricter permission model and fewer targeted malware threats.

Hardware LongevityBreathes new life into older, underpowered computers.

Steeper Learning CurveRequires comfort with the command line or terminal for advanced troubleshooting.

Software LimitationsMajor suites like Adobe (Photoshop, Premiere) and Microsoft Office do not run natively.

Gaming Anti-Cheat HurdlesWhile Steam/Proton handles most games well, competitive titles using kernel-level anti-cheat (like Valorant or Fortnite) will not launch.

Variable Battery LifeOut-of-the-box power management often lags behind Windows on laptops without specific tuning like TLP or auto-cpufreq.

Slide 06 / Windows 優缺點

Windows Pros and Cons Windows 的好與壞

Extensive CompatibilityOffers out-of-the-box support for almost all commercial hardware peripherals and proprietary software.

Superior Gaming SupportDelivers day-1 driver updates and absolute compatibility for every major PC game.

Beginner-FriendlyProvides an intuitive graphical interface that requires no manual configuration for basic tasks.

Enterprise IntegrationStandardized for corporate networks using tools like Active Directory.

Licensing CostRequires paid licenses for professional or enterprise features.

Resource HeavyDemands more memory, background processing power, and storage space, which can slow performance down over time.

Privacy and ControlFeatures forced system updates and telemetry tracking that you cannot easily disable.

Slide 11 / 為什麼這個模式可行？

Why this model
actually works 不是情懷，是工程學

01 Linus's Law

Given enough eyeballs,
all bugs are shallow.

「人夠多，蟲就淺。」
夠多眼睛一起看，沒有藏得住的錯誤。

開源把除錯從「少數人加班」變成「眾人一起看」。問題曝露越早，修得越快。

例子： Heartbleed（2014）影響全網路，但因 OpenSSL 開源，全球在數日內定位、修補並發佈更新。封閉系統的同級漏洞，往往數月後才被爆出。
02 — Kerckhoffs's Principle

Security through
obscurity is not security.

隱晦不是安全。
源自密碼學 — 真正的安全經得起公開檢驗。

把程式碼藏起來 ≠ 安全。把設計攤開來讓全世界檢驗，才是安全。

例子： 加密演算法公開競賽（AES 遴選）反而更可信；靠「沒人看得到」的系統，常在被公開的那天就崩潰。

開頭的數字就這樣解釋：90% 伺服器敢用 Linux，因為它最被盯，也最經得起盯。
Why 90% trust Linux: most watched = most trustworthy.

Slide 12 / 法國 — 數位主權 Souveraineté numérique

France already
runs on Linux. 法國：已經用 Linux 跑了 20 年

不是計畫，是跑了 20 年的事實。法國為數位主權選開源 — 國家資料留在自己手上。
Not a plan — 20 years running. France picked open source for sovereignty.

🇫🇷 How 法國怎麼做 GendBuntu / DINUM

  • 103,164 台 · 97% — 2024 年 6 月，國家憲兵 Gendarmerie 已有 97% 工作站跑自製 Ubuntu 分支 GendBuntu，2024 年 12 月升至 24.04
  • 2004 → 2008 — 先推 Firefox / OpenOffice，再因 Windows XP 終止支援而全面轉向 Ubuntu，省 約 200 萬歐元/年，TCO 降低 40%
  • 2024–2026 — 數位局 DINUM 推 La Suite Numérique 與 60 萬人使用的加密通訊 Tchap（Matrix），並以 GendBuntu 為範本規劃 250 萬公務員遷移
  • 國會全院採用 Ubuntu，巴黎、里昂等城市跟進
關鍵心法：先換應用，再換系統 — 讓使用者先熟悉開源工具，遷移阻力大降。這就是為何法國不重蹈慕尼黑失敗覆轍。
Key trick: apps first, OS second — build familiarity before touching the kernel.

🛡️ Why 為什麼 souveraineté numérique

  • 法律主權 — 避開美國 CLOUD Act 域外調取，資料留在法國主機、可審計、可修改
  • 成本與自主 — 從授權費轉向歐洲支援（Canonical / Collabora），每年 €300–500M 級潛在節省，且維護可控
  • 安全 — ANSSI 2024–2025 指出 Windows 漏洞激增，開源可直接審碼、快速修補
  • 地緣 — 2025 美國 25% 科技關稅後，法國明確把 Linux 遷移定義為供應鏈去風險
一句話：Public money, public code — 公帑產生的程式碼，應該屬於公眾。
France proves open source is not ideology; it's an engineering strategy for a G7 state.
🇫🇷 GendBuntu 2008 → 2024 · 103,164 workstations · 20 years validated → national model
Slide 13 / 德國 — 數位主權 Digitale Souveränität

Germany is moving
its state off Windows. 德國：把整個邦搬離 Windows

最北的邦 Schleswig-Holstein 把 30,000 台公務電腦搬離 Windows / M365，2026 完成 — 不只省錢，為了拿回主導權。
Germany's north is moving 30,000 PCs off Windows/M365 by 2026 — not saving, regaining control.

🇩🇪 How 德國怎麼做 Schleswig-Holstein

  • 2024 年 4 月內閣決議：LibreOffice 為標準，ODF 自 8 月成為官方格式；2025 年 10 月前 70% 工作站完成
  • 六大工程：LibreOffice、Linux、Nextcloud + Open-Xchange/Thunderbird 取代 M365、目錄服務取代 Active Directory、電話系統、Linux 兼容層
  • 2026 年推出自託管 AI LLMoin，以及 30,000 台 Linux 桌面全面鋪開；三層支援：Dataport + 社群 + 企業
  • 2025 年 4 月德國 IT Planning Council（聯邦 + 16 邦）決議：2027 年前 ODF 為全國公務文件交換標準
慕尼黑教訓：LiMux 2006–2017 飽受政治逆轉回到 Windows。Schleswig-Holstein 用分階段 + 法律標準避免重蹈覆轍。
Munich's reversal is why Germany now binds moves to law and formats, not just desktops.

🔒 Why 為什麼 digitale Souveränität

  • 資料主權 — 歐盟資料保護官 EDPS 指 M365 違反 GDPR；CLOUD Act 使美方可調取境外資料，開源 + 自託管可避開
  • Public Money, Public Code — 改進（如 LibreOffice 無障礙功能）回饋公眾，非單一廠商鎖死
  • 經濟 — 2025 年丹麥、荷蘭、德國估算遷移後年省 €15M 起，長線擺脫壟斷授權與高價訂閱
  • 安全與韌性 — 地方可審碼、離線運作、不依賴單一外國供應鏈
Schrödter（邦數位部長）：“We have no influence on the operating processes of such [proprietary] solutions.” — 開源是能否隨時掌控政府 IT 的問題。
Quoted from State Chancellery, 2024–2025.

小字：奧地利軍方 2025 年亦完成 16,000 台遷至 LibreOffice；瑞士 $231M 自建雲端並立法要求政府碼開源。趨勢是全歐。
Small: Austrian Armed Forces (16k) finished in 2025; Switzerland committed $231M sovereign cloud + open-source-by-law. Trend is EU-wide.
