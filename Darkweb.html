運作原理

1. The Multi-Layered Encryption (Why it's called an "Onion")

When your device sends the data, it doesn't just send it raw. Your device encrypts the data three times before it even leaves your computer.

  • Your device wraps the data in Layer 3 (for Node 3), then Layer 2 (for Node 2), then Layer 1 (for Node 1).
  • Node 1 peels off Layer 1. It sees the instructions to send it to Node 2. It can't see anything else.
  • Node 2 peels off Layer 2. It sees the instructions to send it to Node 3.
  • Node 3 peels off Layer 3. It finally sees the raw destination request (e.g., "Go to BBC.com" or a .onion site) and forwards it to the target server.
