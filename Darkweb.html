1. The Multi-Layered Encryption (Why it's called an "Onion")

Your device encrypts data three times before it leaves. Each node peels one layer: Node 1 sees only “send to Node 2”, Node 2 sees “send to Node 3”, Node 3 finally sees the destination (e.g., .onion) and forwards it.

  • Layer 1 for Guard, Layer 2 for Middle, Layer 3 for Exit — wrapped like an onion.
  • No single relay can link you to the final site.

Extra — 補充
Tails

Amnesic OS that routes everything via Tor and leaves no trace on the computer. For journalists who need stronger guarantees.

.onion is safer..onion 更安全

.onion traffic stays inside Tor, never hits an Exit Node — much harder to snoop. No exit = no exit sniffing.

Honeypots:政府/白灰帽釣魚網站

Law enforcement runs fake markets to catch criminals. If a deal looks too good, it probably is a honeypot.
